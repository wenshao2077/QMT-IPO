# QMT打新

个人使用的 miniQMT 新股、新债申购工具：Windows 定时调度、持久化去重、企业微信通知，以及本机桌面控制台。

当前版本：**3.2**。界面默认显示每次任务的运行记录；午间可以查询和校验，提交仍受既有时间窗口约束。北交所未开通权限，明确跳过。

## 功能

- 新股按账户对应市场额度与发行上限取小值；新债不占用新股市值额度，最多10000张。
- Windows 每日自动触发，连接或数据暂不可用时，后续仅处理尚未发起过的项目。
- 提交前保存请求意图；重启、超时、返回不确定时不盲目重报；同时核对已有券商委托。
- 企业微信业务回执确认、UTF-8分页、失败留队补发。
- 图形界面展示真实开关、运行历史、项目结果、通知队列及授权/暂停记录。
- 独立监控与一致性备份。

只处理申购，不提供卖出、自动缴款、资金划转或客户端重启功能。券商已报/已成不等于中签。

## 环境与离线测试

目标环境为 **Windows + Python 3.11 + 已登录的 miniQMT**。界面使用Python自带Tkinter；核心离线测试不需要连接券商。

在源码目录运行：

```powershell
uv run --isolated --no-project --python 3.11 python -B -m unittest -q test_system test_panel test_run_history
```

3.2阶段记录：本机64项测试通过；小黑SSH会话63项通过、1项可见窗口布局检查跳过，并另在真实桌面验证布局。

实际连接所用依赖版本见[requirements.txt](requirements.txt)。安装时使用本项目独立虚拟环境，不修改其他交易程序的环境。

## 配置、部署与边界

本仓库是个人现有部署的源码归档，不是通用安装包。部分PowerShell脚本含现役机器路径及任务名称；迁移前应核对，不能直接运行未知目标的安装脚本。

参考[配置示例](config.example.json)准备执行机器自己的配置。示例默认关闭执行，克隆或安装依赖不会开启交易。现有图形控制台由用户本人确认授权后管理每日任务。

**不要用示例覆盖现场配置，也不要删除原去重账本来重新开始。** 升级应保留同一状态路径及历史请求记录。

仓库仅保存源码、测试、配置示例和说明，不保存：

- 真实资金账号配置、Webhook、访问令牌或密钥；
- SQLite账本、运行日志、任务回执、备份、虚拟环境和行情数据；
- 原始论坛附件包或论坛会员全文归档。

本次GitHub上传不改变小黑的任何运行配置、权限或已启用任务。未配置GitHub Actions，仓库不会在云端连接QMT或执行交易。
