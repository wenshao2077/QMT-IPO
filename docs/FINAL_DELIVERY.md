# QMT 自动打新助手 3.4.0 最终交付

本版整合第一阶段的有限再查询/安装配置、第二阶段的维护诊断，以及第三阶段的离线运行时与统一安装入口，修复本机验收发现的问题。真实券商受理、账户权限和生产升级仍以目标机器证据为准。

## 选择文件

- `QMT-IPO-3.4.0-windows-offline.zip`：本机完整离线交付，含 CPython 3.11.16 x64、Tk、固定版本 wheels 和源码。首次安装无需预装 Python，无需下载依赖。解压后先阅读本说明，双击“开始安装.cmd”。
- `QMT-IPO-3.4.0-source.zip`：开发审查源码，使用自备 Python 3.11 x64。该包自身不含运行时；不把源码包误当离线安装包。
- 外部验收 JSON/说明与 SHA256 文件：绑定最终 ZIP 的测试结果和校验值。校验值验证完整性，不等于发行签名。

离线包的交互安装菜单采用英文以兼容 Windows PowerShell 5.1 的 UTF-8 无 BOM 脚本。菜单含义：1 新安装；2 接续新安装；3 本地配置；4 环境检查；5 打开中文控制台；6 升级；7 回滚；8 健康状态；9 脱敏导出；10 日历覆盖；11 恢复建议。

## 第一次安装

1. 完整解压到本地目录，例如 `D:\QMT-IPO-3.4.0-package`。不能在压缩软件中直接运行；安装根必须在解压目录外。
2. 双击开始安装，选择 1，输入新的空安装根，例如 `D:\QMT-IPO`。安装使用当前 Windows 用户，注册的四个任务默认禁用。
3. 选择 3，在本地图形向导填写自己的账号、已登录 miniQMT 的 userdata_mini 路径和通知地址。窗口关闭不等于保存成功，随后用 4 检查。
4. 选择 5 打开控制台；由本人按控制台既有流程确认启用。安装、检查和打开控制台都不会启用申购。

运行时先进入当前用户 LocalAppData/QMT-IPO/Runtimes 的受保护持久缓存，再创建安装根内的虚拟环境。删除/移动原解压目录不会使新安装失去基础解释器；不要自行删除仍被安装引用的缓存。

每次启动顶层入口先校验全部离线文件。校验失败时保留现场，重新核对交付包。未知文件、被修改的文件、身份不一致都会拒绝继续。

## 已有安装升级

使用已有安装根，选择 6；先关闭旧控制台并等待本程序 worker 自然结束。升级临时关闭本程序任务，更新完成后恢复原开关，保持原解释器/SDK、私有配置和原账本路径，不主动启动任务。不要选择“新安装”，不要逐文件覆盖。

非交互例子（在离线包根目录）：

```powershell
pwsh -File .\setup.ps1 -Operation VerifyPackage
pwsh -File .\setup.ps1 -Operation Plan -Root 'D:\QMT-IPO'
pwsh -File .\setup.ps1 -Operation Upgrade -Root 'D:\QMT-IPO' -ConfirmMaintenance
pwsh -File .\setup.ps1 -Operation Doctor -Root 'D:\QMT-IPO'
```

`-ConfirmMaintenance` 表示调用者已经明确获准对应维护。失败时不删除维护标记、配置标记或委托账本来强行重试，先用 RecoveryPlan。回滚仅恢复代码，不恢复旧订单数据库。暂停不会撤销已开始的在途批次。

## 与 3.3 的主要差别

早间一轮完成后，10:00/11:00/13:00/14:00/14:40 会再次发现项目或额度，15:05 仅核对。已有意图、不确定回报不重发。新增日历前瞻、通知成功时间、暂停后健康诊断、本地脱敏导出、安装接续与完整离线交付。

申购市场、数量、价格、窗口及去重不变。没有新增北交所、多账户、自动卖出、缴款、自动重启 QMT。2027 年度日历仍需有来源的更新，不能根据工作日猜测。

本机交付附公开材料来源及哈希，Python 许可证随运行时、依赖许可证随 wheels 保留。第三方 SDK 的公开下载不等于获得任意对外再分发授权；本包用于 Owner 本机交付，不代表已获得券商认证或正式发行签名。扩大对外交付范围前应核实相关授权。
