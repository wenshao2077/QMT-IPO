# 2026-10-20 图片通知升级

## 用户需求与展示

成功通知仅呈现日期、申购名称、新股或可转债类别、申购成功。跳过的未启用市场、数量、订单号、事件编号及运行说明不进入成功卡片；底部仅保留“申购结果 · 非中签结果”。没有受理项目时显示“今日未申购”，不把跳过当成功。

`REPORTED / SUCCEEDED / CONFIRMED / EXTERNAL_ACCEPTED` 归为已受理。仍有待核对、拒绝、撤单、额度不足或查询错误时保留文字告警，不生成全成功图片。异常摘要也排除未启用市场。预览运行仍保留原文字语义。

## 通知合同

- 图片规格持久化在既有 outbox 的 content 列，以独立版本前缀区分文字；没有数据库结构迁移。旧文字排队记录保留原样，不伪造送达。
- 每页最多六项，超出自动分页。可见结果相同只排队一次，已报转已确认不会重复发成功图；新增项目产生更新后的卡片。
- 企业微信使用 `msgtype=image`、PNG原始字节的base64和MD5，原图不超过2MiB。只在HTTP及企业微信业务回执成功后写入送达确认；渲染或发送失败继续既有持久重试，不降级成成功文字。
- Windows通过系统PowerShell及System.Drawing渲染，使用微软雅黑。渲染器只接收卡片规格，无账户、Webhook及网络权限；临时文件由原进程清理，后台无窗口。系统PowerShell读取ASCII脚本及显式UTF-8 JSON，避免5.1中文脚本解码差异。
- 申购执行、市场范围、价格数量、开关和计划调度不变。升级不主动触发交易任务或发送测试消息。

接口参考：[企业微信消息推送配置说明](https://developer.work.weixin.qq.com/document/path/99110)。本轮网页读取该入口不可用；字段沿用既有企业微信图片接口约定并以隔离请求体校验，实际送达仍须目标Webhook回执。

## 验证

新用例覆盖受理项目筛选、失败与额度不足不冒充成功、空日与分页、真实Windows中文PNG渲染、base64/MD5请求体、发送失败保留待发及重试回执、超限图片拒绝、已报转已确认不重复发送、错误文本排除未启用市场。程序回归及部署状态分开记录，不把图片生成当消息已送达。
