# 3.3.0-rc1 交付审查记录

基线：GitHub main `922f7b1c193b0b3e180ea09b99dc6f1d89411629`。完整改动以源码包和相对该基线的完整补丁交付，不合并 main、不部署生产。GitHub 批量源码写入被工具拦截，因此远端预备分支只有离线导出工作流，没有本轮完整代码提交或PR；不能拿它部署。版本名称是候选版身份，不代表真实券商受理已经验收。

## 修改与原因

交易日闸门从 broker.connect 之后移到之前，并统一申购/监控/界面。修复休市连接失败不断提醒；新增三态返回、严格来源/覆盖验证、QMT数据端独立更新、经来源核对的2026全年兜底、跨年fail-closed和稳定事件去重。移除“get_holidays里有当年日期就补出全年”的旧逻辑。

通知用旁路抑制表保存旧休市纯连接错误的抑制原因，不删除队列、不标记假发送；只在日期确认休市、无当日意图且正文完全匹配时处理。真正的委托结果/异常/未知日期全部保留。另禁止通知与预览入口自动重建丢失的生产账本，避免之后live误用一个空账本。

新安装/升级/回滚分开；去除代码和安装脚本的个人用户名、券商和旧v2固定路径。新安装禁用；升级精确核对任务归属、静止后锁定更新、保留现有配置和账本、恢复原任务开关。旧任务入口保留兼容。新的任务参数有完整引用，固定中国时区，隐藏窗口，限制worker时长；没有QMT重启。

GUI保留原简单控制台，补日历/覆盖、通知失败/抑制、最近运行与无发送配置校验、明确确认的测试通知。修正“未启用北交所”不等于“券商无权限”的措辞，不扩大交易范围。日志不保存原始SDK输出/密钥，旧回执可读且不改写。

回执先校验后归档，完整保留审计；只清理过量且已有足够健康替代副本的旧备份。账本和委托审计不自动清理。对审计归档容量告警，明确保留完整历史不可能同时无限期零增长。

**实际最终执行命令、测试计数和结果以随交付的 TEST_RESULTS.md 及下载的本地测试日志为准；本轮候选代码的Windows/CI测试没有执行。** 本文件不预先把未跑过的Windows测试写成通过。

## 交易语义差异

没有修改价格、数量公式、最小单位、10000张债券上限、市场允许集合、提交窗口、remark格式、已有委托判定或不确定结果处理。实际行为变化仅为有效交易日才准入、未知禁止提交、失落账本在所有任务路径拒绝初始化，以及权限措辞纠正。监控/安装/保留策略均不增加交易动作。

## 失败与回滚

只回源码，绝不恢复过期订单数据库。源替换失败后安全保持维护状态，不承诺任务已恢复。回滚3.2会恢复休市连接缺陷，且旧版忽略通知抑制侧表；必须纳入本机回滚决定。源码备份、维护记录与私有配置备份留本机；这些都不在交付包。
