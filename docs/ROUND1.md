## 恢复策略

ResumeNew 仅服务从未使用的新安装。不为任意损坏提供一键修复，也不提供生产账户变更。配置向导使用与面板启用/暂停相同的 Windows mutex，并持有安装、交易和监控文件锁；实际 Windows 并发行为仍待验证。

配置保存出现正常异常时尽量回退原字节；硬中断/回退失败留下阻断标记，交由本机核验。标记阻断通过现有 validate_config 链路生效。升级和回滚只处理源码及来源身份，不回滚配置或委托历史。

## 本轮不包含

完整离线运行时/SDK依赖包、EXE 安装器、签名/SBOM/再分发授权、无人值守自启动 QMT、通用多券商认证、生产账户变更与授权版本绑定、一般性修复/卸载、跨年日历自动更新、第二通知渠道、中签/缴款自动化。这些没有用文档假装已经实现。
