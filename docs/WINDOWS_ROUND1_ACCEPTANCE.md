人工菜单和 AI 非交互方式使用同一底层流程；比较配置默认值、四个禁用任务、源码身份、脱敏 JSON 及退出码。验证未默认下载依赖，日志仅留本机，正常或错误结果不输出账户/密钥。

在 venv、源码初始化前后、依赖下载、各禁用任务注册、快捷方式步骤注入中断。能够独立证明完整的未使用安装应接续；损坏/丢失账本、残缺配置、来源变化、已有意图、授权记录存在等情况必须停止，账本不得被重新创建。
